# IIT_Legends_2026-2027

This directory is dedicated to the IIT Legends batch of 2026-2027.

## About

A collaborative space for IIT students (batch 2026-2027) to share Data Structures and Algorithms (DSA) learning resources, solutions, and projects.

## Structure

- Add your DSA solutions and learning materials here.
- Organize by topic (e.g., Arrays, Linked Lists, Trees, Graphs, Sorting, etc.).

## Getting Started

1. Clone the parent repository.
2. Navigate to this directory:
   ```bash
   cd IIT_Legends_2026-2027
   ```
3. Start contributing!

## Contributing

- Follow the naming conventions used in the rest of the repository.
- Add comments to your code for clarity.
- Happy coding! 🚀
